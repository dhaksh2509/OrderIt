# OrderIT - Frontend Client

This directory contains the React 18 + Vite frontend client for **OrderIT**.

For full project details, setup instructions, and architecture overview, please refer to the [Main Root README](../README.md).

## Available Scripts

In the `frontend` directory, you can run:

- `npm run dev`: Starts the Vite development server with HMR.
- `npm run build`: Builds the production bundle into `dist/`.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Runs ESLint check across source files.
